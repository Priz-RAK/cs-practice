git diff — это команда в Git, которая показывает различия между двумя состояниями проекта
 Команда git diff --staged показывает изменения, которые уже добавлены в индекс (промежуточную область, staging area) и, следовательно, войдут в следующий коммит
 Команда git status — это ваш главный инструмент, чтобы в любой момент понять, что сейчас происходит в репозитории. Проще говоря, она отвечает на вопрос: «Что изменилось с момента последнего коммита и что готово к фиксации?»
